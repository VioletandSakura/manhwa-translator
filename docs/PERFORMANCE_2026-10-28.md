# 性能与编辑效率验收

日期：2026-10-28。本轮目标是改善批量任务响应、重复编辑与人工检查，同时修正识别配置和竖排阅读顺序。全部基准使用本机、独立数据库、空凭据后端和自产图片，付费 API 请求为0。

## 已完成

- 修正高精度 OCR 切回普通模式时参数残留的问题。恢复的是引擎首次加载时的真实默认值，模型初始化、配置和推理使用同一把可重入锁。
- 相邻竖排列按右到左合并，横排仍按从上到下、从左到右排列；补充不同输入顺序的检查。
- 低置信度复识别保留最多6个候选及原有接受规则；图片按需生成，只有连续两次相同、高置信且通过接受规则的结果才提前结束。预算和早停可在引擎构造参数中控制。
- 导入、任务创建、队列装配、文本导入/导出和 ZIP 打包放入后台。任务和全部页面在一次数据库事务中创建。准备期间的暂停、取消和退出会保留最新意图。
- 队列传递页面状态快照，100毫秒合并刷新，仅重画变化行；最终结算仍读取持久化状态。同一次尝试中的旧阶段、较旧重试的消息不会覆盖新结果。
- 修改文字、字号、颜色、对齐或目标框位置时，可以复用校验过的擦字底图。原图像素、有效蒙版、保护区域、原文擦除范围、引擎或模型变化时重新计算；底图文件校验失败也会重建。原图仍要解码并计算签名，不能把这项优化解释成零读图。
- LaMa 最多缓存一个模型会话，模型身份变化时重建；没有为每页保留额外的大图内存缓存。
- 仅识别或没有可绘制译文时，跳过空擦字和 Pillow 转换，一次读源文件、一次 PNG 编码，保留原有工件路径和原图内容。
- 导入人工译文时先完整校验全批，再事务保存真正变化的文档，仅重绘这些页；无变化不写盘、不重绘。
- 蒙版每一整笔支持撤销/重做，保存触及区域的64px瓦片差异；画笔只更新受影响区域，避免每次移动都转换整页蒙版。拖动文字框也会记录一次撤销。
- 编辑器显示排版溢出提醒和待检查数量。“下一处待检查”或 F8 在当前页跳转，本页全部处理后寻找当前任务的其他页；跨页前保存当前编辑，搜索期间锁定编辑区，避免新输入被覆盖。

## 基准方法

修改前保存完整 app 源码快照及逐文件哈希，位于本地忽略目录 `.artifacts/perf-baseline-snapshot/`。基准脚本通过 `--code-root` 在独立进程中载入优化前或优化后的代码。未公开的本地快照不随源码发行，仓库中的脚本可以复现当前版本的测量。

固定图片为1200×1600和1600×2400两张英文气泡图。检测模型为本机已安装的 RapidOCR 3.9.2 / ONNX Runtime 1.28.0；Python 3.12。分别测首次模型推理、同图与第二图热推理、两页仅识别流水线、首次和后续样式重绘。CPU时间、进程内存、样本与输出哈希均写入报告。

优化前、后各3轮，保留逐轮结果并取中位数。后续重复采用优化前/后交替顺序，运行期间不并行执行其他项目测试。初次探索的中间版本不混入最终统计。GUI基准是在200/500页的队列上回放40条进度消息，不能当成整本漫画的翻译性能。

## 结果

| 指标，3轮中位数 | 优化前 | 优化后 | 解读 |
| --- | ---: | ---: | --- |
| 500页队列、40条进度消息的兼容回调 | 0.2909秒 | 0.0130秒 | 避免整表刷新；不含特意加入的150毫秒事件等待 |
| 对应表格行更新次数 | 20,000 | 40 | 从每条消息更新全表改为变化行 |
| 真实状态快照通路的界面数据库读取 | — | 0次 | 与兼容回调分开报告，不把异步派发当成同步完成耗时 |
| 缓存建立后的重复样式重绘 | 0.2221秒 | 0.0939秒 | 约减少58%的墙钟耗时，限本次样本 |
| 两页仅识别完成后的输出阶段 | 0.2463秒 | 0.0855秒 | 约减少65%，限输出阶段 |
| 两页仅识别端到端 | 3.689秒 | 3.880秒 | 本次中位数约慢5%，不能宣称整体提速 |
| 首次样式重绘 | 0.2478秒 | 0.2906秒 | 本次约慢17%，首次建立和校验缓存有额外工作 |
| 同图热 OCR | 1.314秒 | 1.279秒 | 差异小、波动大，没有稳定提速结论 |
| 第二张图热 OCR | 2.133秒 | 2.202秒 | 未改善 |
| 冷 OCR | 2.707秒 | 2.681秒 | 差异很小 |

| 结束时私有内存 | 398.7MiB | 399.9MiB | 基本相当 |

固定样本 SHA256、识别文字和重绘结果 SHA256 前后一致。追加4轮共16次真实推理中，检测框完全一致、识别置信度最大差0.0，实际普通模式参数均为 `2000 / 736 / min`。这些检查没有发现分辨率或识别结果回归，但不能代替真实复杂日漫质量评估。

蒙版局部存储的独立样本中，一笔历史保存49,152字节，而整张灰度蒙版为760,000字节。这证明没有逐笔复制整页，不代表全应用内存下降相同比例。

原始统计位于 `.artifacts/performance-three-run-summary.json`；逐轮报告及当时源码哈希在其列出的目录中。正式计时后补充了过期进度过滤、初始化意图与跨页编辑锁定的安全检查；这些收尾修复未改变表中被测图像计算负载。Windows的短时CPU计时精度与工作集回收会影响测量，报告中的0.0秒不代表没有计算。

## 正确性与操作验收

新增回归覆盖：批量单事务及失败回滚、导入/打包时界面响应、准备期间取消与退出、仅变化行更新、乱序进度保护、人工译文仅改页重绘、跨页前保存并保护输入、真实编辑器连续修改保留新底图缓存、原图/蒙版/状态变化失效、蒙版撤销与局部存储、拖框撤销、检查导航和高精度参数恢复。

最终完整测试：297项通过，用时29.49秒。

- 真实桌面主流程：仅识别、人工修改、重绘、菜单导出 TXT/JSON/ZIP 通过；回调在 GUI 主线程，未编辑的输出像素与原图一致。证据：`.artifacts/perf-desktop-final/report.json`。
- 设置与编辑流程：字体、预设、样式、竖排、蒙版重开、保护待检查区域和原图恢复均通过。证据：`.artifacts/perf-settings-final/report.json`。
- 真实子进程中断恢复：在检测、翻译完成和文件保存三个检查点强制结束测试进程，恢复后均完成任务；已完成页未重做，归档 CRC 正常；人工译文导入中断后全批回滚。证据：`.artifacts/perf-crash-final/report.json`。
- 界面验收：125%显示缩放、1024×700至1440×900窗口，共19张真实 Qt 截图，无脚本错误；另外检查窄编辑器中的排版提醒可见、蒙版撤销/重做像素一致。证据：`.artifacts/perf-ui-final/report.json` 与 `.artifacts/editor-efficiency-proof/report.json`。

所有验收均使用独立样本，未读取系统翻译凭据，付费 API 请求为0；原生文件和颜色选择对话框在自动化流程中由测试替代。此处不把离线流程验收描述成付费服务联网验收。

当前版本基准可运行：

```powershell
.\.venv\Scripts\python.exe scripts\benchmark_performance.py --output-dir .artifacts\performance-run-01
```


这轮收益主要在界面响应、重复编辑和输出阶段。没有更换 OCR 模型、引入 GPU 依赖或加入章节级翻译上下文；复杂竖排标点、真实日漫大批量质量和发布安装验收仍需后续工作。
