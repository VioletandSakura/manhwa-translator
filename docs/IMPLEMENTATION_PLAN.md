# 功能对照与实现计划

## 对照原则

早期参考项目仅用于确认功能范围和用户体验。本项目采用独立模块化实现；开源前仍需复核代码引用、资源及模型许可。

当前实际打磨进度与待验收项以 [首次开源计划](OPEN_SOURCE_ROADMAP.md) 为准；下列阶段列表是早期规划，不代表每个界面选项都已完整接通输出。

## 第一阶段：可运行MVP

- 单图导入；
- 本地PP-OCRv6检测与OCR；
- DeepSeek OpenAI Compatible翻译；
- OpenCV擦字和Pillow中文渲染；
- SQLite任务、配置、页面检查点和翻译缓存；
- Windows凭据管理器；
- 中文界面、逐阶段进度和预览；
- 分离保存原图、修复图、译图和JSON。

## 第二阶段：个人可用版

当前状态：核心能力已实现并接入中文桌面界面。

- 多图、文件夹、ZIP和EPUB；
- EPUB2/EPUB3 OPF与Spine顺序解析、安全解包、章节和页序映射；
- 队列、暂停、继续、取消、失败重试和重启恢复；
- 多API通道、优先级、轮询、RPM限制和故障切换；
- 术语表、提示词、替换规则、预设和历史；
- 日漫专用检测与MangaOCR适配器；
- LaMa ONNX可选擦字器及OpenCV降级；
- TXT/JSON导入导出；
- 单页可视化编辑器和实时逐页预览。

未自动安装的可选项：MangaOCR约400MB模型及其PyTorch依赖、LaMa ONNX模型。模型路径和下载策略记录在`models/manifest.json`，必须由用户确认后手动准备。

## 第三阶段：高级功能

- 明确标识的视觉模型上下文翻译；
- AI OCR、可选AI上色和局部AI渲染；
- 本地超分、去噪、CPU/GPU切换和显存释放；
- 替换翻译、高级批处理和PSD分层导出。

## 暂不实现

- 登录、账号、多用户、云数据库和Web服务器；
- macOS和Linux发行版；
- 默认整页AI重绘；
- 内置数GB级本地翻译大模型；
- 第一阶段PSD、PDF、CBR和7z。
