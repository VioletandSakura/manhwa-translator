# 第三轮验收：批量任务与失败恢复

日期：2026-10-28。Windows 本机、项目现有 Python 3.12 / PySide6 环境。所有故障注入使用独立测试目录、自产英文气泡图片、真实 RapidOCR 和离线翻译夹具；本轮付费 API 请求为0，不模拟声称真实服务发生了故障。

## 已实现的行为

| 场景 | 现在的行为 |
| --- | --- |
| 上次进程意外结束 | 启动将遗留 running 页转为 pending，任务转为 paused；完成页、译图、缓存和失败信息保留，不自动开跑 |
| 重复启动程序 | 使用本地进程锁阻止第二个实例操作同一数据库，避免把仍在运行的任务误判为中断 |
| 并行处理 | 总体百分比只按成功完成页数计算；阶段与失败数量分开显示，晚到的进度消息不覆盖完成状态 |
| 暂停 / 继续 | 当前不可中断步骤结束后，在流水线步骤边界等待；继续后执行下一步 |
| 取消 | 当前步骤结束后停止，不再启动后续步骤、等待页或自动重试；完成页保留，可从历史恢复 |
| 退出 | 托盘菜单退出时等待后台 QThread 和当前步骤结束；未完成页保持可恢复，后台结束后才真正退出 |
| 单页重试 | 只运行选中的失败/取消页；不允许重试完成页，也不连带重跑其他失败页 |
| 恢复任务设置 | 新任务保存翻译开关、语言、阈值、OCR/擦字引擎、字体及并行数；恢复时还原，防止仅识别任务意外变成付费翻译 |
| 查看已完成历史 | 直接载入结果供编辑/导出，不需要验证 API 或创建新翻译线程 |
| 翻译数量不匹配 | 只对出错块拆为两块尝试修复，子块不递归重试；修复失败停止本页，不猜测译文对应关系，不自动换通道或重跑整页 |
| 部分翻译成功 | 缓存每个成功块；后面的块失败或翻译之后被中断，重试时复用先前缓存 |
| 输出工件保存 | 原图副本、擦字图、译图及页面 JSON 在同目录写完并同步后替换，替换失败保留旧文件 |
| 原图归档 | 先写临时 ZIP，完整读取并检查文件清单、CRC、与副本的 SHA256，再替换为正式归档，之后才删除散文件 |
| 归档删除副本中途结束 | 完整归档已在磁盘；下一次调用会核验剩余副本再继续清理，既有坏归档不会导致副本被删除 |
| JSON 人工译文 | 按 page_id / 原图路径及文本框 ID 匹配；页面顺序可改变，原文必须匹配，只更新译文，保留位置、样式及人工检查状态 |
| JSON/TXT 保存中断 | 所有内容先预检，备份与新文件准备完成后才替换；失败回滚全批，进程中断后通过恢复日志还原全批旧译文 |

API 通道、提示词、术语表和替换规则在恢复任务时使用当前配置，其缓存会区分配置。早期任务没有处理设置快照时，日志提示本次按当前面板设置运行。改变项目位置不会迁移旧输出目录；输出目录访问失败仍需用户重新选择可用位置另建任务。

## 验证边界

- “安全退出”会等待当前 OCR/请求结束或网络超时，不保证立即退出；已经发出的付费请求仍可能由服务商完成计费。
- 进程强制结束已实测，未测试突然断电、磁盘硬件故障或文件系统损坏；导入恢复依赖本地备份文件仍然存在。
- 中断的未完成页面从页首重新识别，使用翻译缓存减少重复调用；没有把 ONNX 推理进行到一半的内存状态保存下来。
- 部分导入后的重绘失败会保留已成功提交的人工译文；修复问题后可以重新重绘，译图不保证整批同时切换。
- 尚未做数百页持续压力测试、真实服务故障注入或干净 Windows 安装验收；这些不应写成已完成。
- 本轮改动仍在本地，未提交/推送 GitHub，也未选择许可证或公开发布。
