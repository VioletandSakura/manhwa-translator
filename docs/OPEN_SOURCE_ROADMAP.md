# 首次开源前的打磨计划

目标是让一个没有项目背景的 Windows 用户能够安装、跑通一页、理解结果并报告问题。先稳定完整流程，再考虑新增高级功能。

## 第一轮：可复现的基本流程

- [x] 路径跟随源码目录，去掉启动器和安装脚本中的个人 D 盘路径。
- [x] 开始任务前探测实际写入权限，避免多页重复报相同的目录错误。
- [x] OCR-only 模式保留原图，不在缺少译文时擦除文字。
- [x] 从队列表格进入编辑器，并保存译文、重绘和导出。
- [x] 输入框手动改路径时清除旧文件选择，选择窗口显示 CBZ。
- [x] 编辑面板可以滚动，保存时收集尚未点击“应用”的译文，文字修改可以撤销。
- [x] 后台任务的完成与失败回调返回界面线程；澳门系统区域下的数字控件使用阿拉伯数字。
- [x] 无控制台启动入口，兼容旧 uv 环境的错误 pythonw 启动程序；启动器退出后应用独立运行。
- [x] 新增自制样本的真实 Qt 桌面流程检查；个人数据、旧环境和检查产物排除在 Git 外。

后续已通过真实 DeepSeek 小样本测试：3 次生成请求、387 tokens，覆盖日文翻译、英文样本 OCR 后翻译、重绘、导出与缓存。此前已有 GitHub 私有仓库，本轮改动尚未上传，许可证仍待选择。远程现状见 [GitHub 核对记录](GITHUB_STATUS.md)。

## 第二轮：消除“看起来支持，实际没生效”的设置

- [x] 把术语表、自定义提示词和替换规则实际接到翻译流程，并验证缓存会区分不同设置。
- [x] 接通全局字体、字号范围与单个文本框的颜色、对齐、描边、旋转。
- [x] 让蒙版参与实际重绘；能重新打开已保存的蒙版，并提供清晰的前后预览。
- [x] 明确人工检查状态的接受/拒绝方式，验证低置信度与效果字不会被误擦。

验收：每个显示为可用的设置，至少有一个结果文件能证明它确实改变了预期行为。

2026-10-28 第二轮已验收：新增像素与界面回归检查，真实 DeepSeek 两次生成请求合计290 tokens。原图与译文框分别保存擦字范围，避免移动或放大译文框时误擦气泡边缘。证据与边界见 [第二轮记录](QA_ROUND2_2026-10-28.md)。

## 第三轮：批量任务与失败恢复

- [x] 启动时把中断任务转为可恢复状态；历史页显示中文状态与准确页数。
- [x] 并行时按已完成数量计算总体进度，避免页序导致进度回退。
- [x] 明确暂停、取消、单页重试和关闭窗口的行为，等待后台工作安全结束。
- [x] 按页或按块处理翻译数量不匹配，减少整页反复调用。
- [x] 原图压缩归档在删除输出副本前校验 ZIP 内容和 CRC；验证中断不会造成损失。
- [x] JSON 人工翻译按页面标识匹配，并在导入前完整校验，避免部分更新和页面顺序错误。

验收：在多页任务的检测、翻译、保存等阶段中断，能够解释状态、重试并保留已有结果。

2026-10-28 第三轮已验收：真实 OCR 子进程在检测、翻译结束、文件保存三个位置被强制结束后均可恢复，完成页不重跑，已翻译块复用缓存；JSON 导入在实际替换第一份文件后强制结束，重开可回滚全批。付费 API 请求为0。证据与边界见 [第三轮记录](QA_ROUND3_2026-10-28.md)。
