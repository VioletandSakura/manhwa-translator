## 数据保护与边界

重绘从输出的原图副本、原图 ZIP 或导入源文件读取底图，不以先前擦过字的结果反复加工。旧结果只剩修复图时允许有限编辑，并明确提示无法完整恢复原文。

原文字形坐标和译文排版坐标分开保存。拖动、扩大或旋转译文框不扩大自动擦字范围；手动添加区域默认不擦除背景，可以用补充蒙版明确指定要擦除的部分。

字体范围不合法、字体文件缺失或不可加载时，在开始任务前提示。损坏或尺寸不匹配的蒙版不会替换编辑器当前已经打开的页面。

本轮没有向 GitHub 推送，也没有完成第三轮的批量中断恢复、归档完整性、JSON 导入事务或发布安装验收。
